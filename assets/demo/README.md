# Maple & Main demo photography

Original images generated with the OpenAI image-generation tool on September 30, 2026 for Crave.
Maple & Main is a fictional American restaurant concept, not a customer testimonial.

- `smash-burger.jpg`: double smash burger, American cheese, pickles, lettuce and house sauce on a potato bun, crinkle-cut fries, ivory plate, warm neighborhood grill setting.
- `crispy-chicken.jpg`: buttermilk fried chicken, dill pickles, lettuce and honey-pepper mayo on a potato bun, matching setting.

Images are optimized JPEG encodings of the generated originals, licensed with the template under MIT.
The exact bytes and provenance are recorded in `distribution/asset-ownership.json`.
The demo uses commit-pinned HTTPS URLs to these files to retain the SDK's public-image contract on
all platforms. Update `src/demo/maple-main-assets.ts` when changing the assets.
